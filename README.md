# AI Society — Club Event Website

## About
The AI Society website provides information about university club events and allows students to register for upcoming activities. It includes event details, a registration form, and a section to view saved registrations. The website is built using HTML5, CSS3, and JavaScript.

## Website Pages
- **Home (`index.html`):** Introduces the AI Society and highlights an upcoming event.
- **Events (`events.html`):** Displays club events with their dates, locations, and descriptions.
- **Register (`register.html`):** Allows students to register for events and view or clear saved registrations.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run Locally
1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Use the navigation menu to visit the Home, Events, and Register pages.
